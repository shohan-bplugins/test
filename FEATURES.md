# Easy 3D Viewer — feature list

Every feature below is included on **every plan, including Free**. Plans differ
only in how many products and models you can publish — never in what the viewer
can do.

Written for listing bullets, comparison tables and ad copy. Grouped by what a
merchant is trying to do, not by how the app is built.

> Two claims to keep accurate wherever these bullets are reused:
> **iPhone AR needs a separate .usdz file** the merchant supplies, and the
> drag-and-drop blocks need a **modern Shopify theme** (older themes use the
> copy-paste embed instead). Both are marked inline below.

---

### On the storefront

- Drag to rotate, scroll or pinch to zoom
- Pan the model, on stores that want it
- Works on desktop, tablet and mobile
- Optional auto-spin, so the product turns on its own
- Fullscreen button
- Reset-view button, to return to the starting angle
- Snapshot button — the shopper saves an image of the current view
- Zoom in / out buttons for people not using a mouse wheel
- Optional on-screen axis guide
- Choose whether dragging on the model scrolls the page on touch and on scroll wheel
- Loads only on pages where a model is placed, and only once a shopper scrolls to it

### Augmented reality

- **iPhone** — Apple Quick Look *(needs a .usdz file the merchant supplies)*
- **Android** — Google Scene Viewer
- **In-browser** — WebXR on supported Android devices
- Nothing for the shopper to install
- Each AR method can be switched on or off individually

### Look and lighting

- Background colour of your choice
- Brightness (exposure) control
- Five tone-mapping styles for different looks
- Studio lighting from built-in environment maps
- Bring your own HDR lighting or backdrop image
- Optional blurred backdrop
- Contact shadow under the product, for a grounded look
- Set the viewer's height on the page

### Camera

- Set the exact angle the model first appears at — turn and tilt
- Set the starting zoom level
- Automatic framing, or a custom field of view
- Keeps the product the same size when the browser is resized

### Animation

- Plays animations already built into the model
- Choose which animation starts by default
- Loop one, loop all, or play once
- Optional on-screen switcher so shoppers can pick an animation

### Product variations

- Show a specific material variation from a single file — one model can cover
  several colourways

### Where you can place it

- **Product pages** — picks the model up from the product automatically
- **Any other page** — home, landing pages, blog posts, using a Model ID
- **Anywhere else** — a copy-paste embed for places a theme block can't reach,
  in a responsive box or at a fixed height
- **A shareable link** for every model, for email, chat or social

### Managing your models

- Upload from your computer, or pick a file already in your Shopify Files
- Drag and drop
- A searchable library, sortable by newest, oldest, name or size
- List or grid view
- Select several models and delete them together
- One-click copy of a model's ID, file link or embed code
- See file size and upload date at a glance
- Search your products and see instantly which have a model

### Setting up

- Guided checklist that walks through the three setup steps
- One button to add the viewer block to your theme
- Built-in check that tells you what your theme can and can't see, with the fix
- Live preview beside every setting, showing exactly what customers will see
- Unsaved-changes bar, so nothing goes live by accident
- Documentation and video walkthrough inside the app
- Support ticket form inside the app — no need to leave your store admin

### Your dashboard

- How many products and models you're using, against your plan
- Uploads over time, by day, week or month
- A breakdown of your file types
- Your most recently added models
