# The 3D Model Library

Standalone models that aren't tied to a product: drag-and-drop upload, search and sort, list and grid views, bulk delete, and the three things every row can copy.

Runtime 2:59 · 17 scenes.

---

### 01 · Title — `0:00`

Not every model belongs to a product. A showroom piece on your home page, a material sample in a blog post, a packaging render on an About page — those live in the 3D Model Library.

### 02 · The library — `0:12`

Open 3D Model Library from the nav. Each entry is a model file plus a name, its own viewer settings, and a permanent Model ID you can paste anywhere.

### 03 · Product vs library — `0:22`

Worth being clear on the difference. A product model is attached to a product and drawn by the product block automatically. A library model is standalone — you place it deliberately, by ID or by embed code. The same file can be both.

### 04 · Drop zone — `0:37`

Uploading is a drop zone. Drag a .glb straight from your desktop onto it, or click it to open a file chooser. Same twenty megabyte ceiling, same glb and gltf formats, same Shopify Files storage as the product screen.

### 05 · Drag over — `0:52`

The zone highlights as you drag over it and tells you to release.

### 06 · Uploading — `0:56`

Drop, and it uploads. Note it also syncs your shop library metafield straight afterwards, which is what makes the new Model ID resolvable on the storefront without you touching Setup.

### 07 · Uploaded — `1:07`

And it appears in the list, newest first, with its size and date.

### 08 · Choose from Files — `1:12`

Choose from Files works here too — import a model already in your Shopify Files into the library without re-uploading it.

### 09 · Search and sort — `1:19`

Search filters by name as you type. Sort gives you newest, oldest, name A to Z, or largest first — largest first is the useful one when you're hunting for the file that's slowing a page down.

### 10 · Grid view — `1:31`

There's a grid view as well as the list, toggled top right. Same actions, more per screen.

### 11 · Three copy buttons — `1:38`

Every row has three copy buttons and they're for three different jobs. ID copies the Model ID — that's what the Any Model theme block wants. Embed copies a ready-made iframe snippet for anywhere that accepts HTML. URL copies the raw glb file address, for when you need the file itself.

### 12 · Copy ID — `1:56`

Click ID, and it's on your clipboard with a confirmation. Paste that into the theme block and the model appears, complete with its saved settings.

### 13 · Bulk select — `2:04`

For tidying up, tick the checkboxes — they appear on hover — or use Select all. A blue bar tells you how many are selected and gives you Delete selected.

### 14 · Delete is safe — `2:14`

Deleting is safer than it sounds. It removes the library entry — the name, the settings, the ID — but the glb file itself stays in your Shopify Files. You're not destroying an asset, and you can re-import it.

### 15 · Plan limit — `2:27`

If you hit your plan limit, the drop zone dims and a banner explains the arithmetic: how many models in the library, how many product assignments, and the reminder that a file used in both counts once.

### 16 · Open a model — `2:40`

Click any row to open the model. This screen gets its own tutorial next, because it's where sharing and embedding happens — but note it has the same viewer settings you learned on the product screen, saved against this library entry.
